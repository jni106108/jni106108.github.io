# Identidade visual — Lancer Club 67

Para trocar o logo, substitua o arquivo **mantendo o mesmo nome** e envie para o GitHub.
Depois troque `CODIGO` em `sw.js` (ex.: `lancer-codigo-v7.1`) para os celulares buscarem as imagens novas.

| Arquivo | Onde aparece |
|---|---|
| `icone-192.png`, `icone-512.png` | ícone do app instalado (cantos arredondados) e ficha do veículo |
| `icone-mascaravel-512.png` | ícone "maskable" do Android (fundo até a borda; o Android recorta em círculo/squircle) |
| `apple-touch-180.png` | ícone no iPhone/iPad |
| `favicon-48.png` | aba do navegador |
| `icone-1024.png` | original do ícone LC67 em alta resolução (fonte para gerar os outros) |
| `abertura.png` | escudo da tela de carregamento |
| `logo-completa.png` | brasão "Lancer Club 67" (ainda não usado no app) |
| `logo-simplificada.png` | silhueta do carro com "67" (ainda não usada no app) |

- O ícone LC67 foi redesenhado em alta resolução a partir do conceito; para regerar (outra cor, outro texto),
  edite e rode `ferramentas/gerar-icone-lc67.ps1` no Windows.
- `abertura.png`, `logo-completa.png` e `logo-simplificada.png` foram recortados da imagem do conceito
  (resolução limitada). Quando houver os arquivos originais do designer (SVG ou PNG grande), substitua-os aqui.
